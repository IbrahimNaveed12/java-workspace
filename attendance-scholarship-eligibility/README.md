# Attendance Scholarship Eligibility

## Problem Summary
Check scholarship eligibility using CGPA, family income, and attendance.

## Logic
The program checks the next requirement only after the previous one is met: CGPA must be at least 3.5, income at most 80,000, and attendance at least 75%.

## Run
Compile and run with `javac AttendanceScholarshipEligibility.java` and `java AttendanceScholarshipEligibility`.
